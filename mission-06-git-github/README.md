## 4. My understanding
**Difference between staging and committing:**
Staging = choosing what to include. Committing = permanently saving that choice into Git history.



**What a branch is and why it is useful:**
A branch is an independent line of development in Git. When you create a branch, you get a separate workspace where you can make changes without affecting the main codebase (usually main or master).

**What a Pull Request is and why it is useful:**
 pull request is a formal proposal to merge changes from one branch into another (usually into main)/ the parent branch
